# Wenqing Deng HW2 portfolio

Static semantic HTML portfolio for CSE 134B HW2 Part 2. This repository is independent of HW1.

Pages: index.html, about.html, projects.html, agentai.html, onlineorder.html, resume.html, contact.html, experiments.html.

Open index.html to browse locally, or serve this directory with a static HTTP server. Netlify publish directory: repository root. No build command or frontend framework is needed.

Only border styles and scoped project-summary CSS are used. The scripts in experiments.html are limited to the console-only custom element and a static canvas drawing. The contact form is disabled and sends nothing.

The diagrams and notification tone are original demonstration assets. The flower video is from MDN's video example. MathML support sources are linked on experiments.html.
